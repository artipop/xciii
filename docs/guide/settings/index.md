# Настройки

Настройки приложения собраны в одном окне: внизу левого списка, под
«+ Добавить доску», кнопка **«Настройки»** с шестерёнкой. Они действуют на все
доски. Разделы:

- **«Приложение»** — тема, язык, справка и обратная связь;
- **«Агенты»** — агенты этой машины и чем они запускаются, см.
  [«Агенты, npx и Node.js»](./agents.md);
- **«Настройки прокси»** — именованные сетевые настройки, на которые ссылаются
  агенты;
- **«Доступ с телефона»** — см. ниже;
- **«Импорт и экспорт»** — экспорт и импорт архива досок, см.
  [«Перенос»](../transfer.md);
- **«Прочее»** — инструкция для разговора без карточки, «Сообщать, когда агент
  ждёт ответа» и сведения об установке.

Разделы, которые эта сборка не поддерживает, не показываются: на машине без
агентов остаются «Приложение», «Импорт и экспорт» и «Прочее».

## Приложение: тема, язык, справка

- **Тема** — «Светлая», «Тёмная», «Как в системе». Применяется сразу.
- **Язык** — список языков приложения. Если язык не выбирали, действует язык
  системы.
- **Справка** — «Руководство», кнопка «Открыть»: открывает это руководство.
  Ниже — «Дать обратную связь», кнопка «Написать»: открывает почтовую
  программу с адресом `hello@deffun.com`. Адрес написан и рядом с кнопкой —
  его можно скопировать, если почтовая программа не открылась.

Всё это доступно и до создания первой доски. Выбранные тема и язык хранятся
самой установкой: они переживают перезапуск и действуют и на телефоне через
[«Доступ с телефона»](#доступ-с-телефона).

## Доступ с телефона

Приложение может стать узлом вашей сети Tailscale и отдавать доску вашим
устройствам. Наружу ничего не публикуется; по умолчанию доступ выключен.

1. Задайте **«Имя этой машины в сети»**.
2. Нажмите **«Отдавать доску»** и подтвердите машину по ссылке, которую покажет
   приложение.
3. Рядом появится адрес («Откройте это на телефоне») с кнопкой «Скопировать».

На телефоне нужен клиент Tailscale под тем же аккаунтом; адрес работает только
внутри вашей сети. По нему открывается доска и `/m` — телефонная версия с
вкладками Входящие, Карточки, Ждут, Терминалы.

## Уведомления агента

Переключатель **«Сообщать, когда агент ждёт ответа»** — в разделе «Прочее».
В выключенном состоянии он убирает только уведомления; янтарная кнопка
терминала на карточке остаётся.

## Файл настроек

Часть настроек агентов в окно не вынесена: их меняют редко, и правятся они
руками в файле. Он лежит в каталоге установки:

- macOS — `~/Library/Application Support/XCIII/acp/config.json`;
- Windows — `%AppData%\XCIII\acp\config.json`;
- Linux — `~/.config/XCIII/acp/config.json` (или `$XDG_CONFIG_HOME`).

Приложение при правке файла лучше закрыть: оно перечитывает его при запуске.

| Ключ | Что задаёт |
|---|---|
| `maxConcurrent` | сколько сессий работает одновременно на этой машине (по умолчанию 3) |
| `sessionTimeoutMinutes` | сколько может длиться один ход агента (15) |
| `testTimeoutMinutes` | сколько может длиться один прогон тестов (30) |
| `sessionIdleMinutes` | сколько сессия ждёт между ходами (30) |
| `autoAllowTools` | какими инструментами агент пользуется без подтверждения. У сессии, запущенной карточкой, спросить некого, поэтому всё, чего нет в списке, ей запрещено |
| `worktreeMode` | `always` — своя рабочая копия git на сессию, `never` — по одной карточке проекта за раз. Это же видно в разделе «Прочее» |
| `artifactsDir` | куда складываются скриншоты и отчёты тестовых прогонов |

Колонок и маршрутов в этом файле нет: автоматика лежит на самой доске и
уезжает вместе с ней в экспорт и в шаблон.

## Чего здесь нет

Настройки конкретной доски — колонки, маршруты, папки проектов, инструкции
агентам — задаются в самой доске, в окне
[«Как работает эта доска…»](../automation/index.md).

Там же — **«Куда деплоить»**: цели деплоя показываются только на доске, где
есть колонка с деплоем, потому что остальным доскам они ни к чему.
