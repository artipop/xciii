# Правила: условия на стрелках

Обычно событие — одна стрелка: шаг прошёл, карточка поехала. Условия нужны,
когда этого мало. Их три вида — по тому, кто принимает решение: доска, агент
или человек.

## По свойству карточки

Пример: «Шаг прошёл → в Деплой, но только если Приоритет = Высокий; остальные —
в На ревью».

В панели стадии под стрелкой есть **«+ ветка по условию»**: появляется вторая
стрелка на то же событие. Условие — свойство доски и его значение, оба
выбираются из списков. Срабатывает первая стрелка, чьё условие выполнено;
стрелка без условия — запасная. Условие подписано на самой стрелке («если
Приоритет = Высокий»).

Если событие пришло, ни одно условие не подошло и запасной стрелки нет,
карточка остаётся на месте и пишет об этом в комментарий. Поэтому запасную
стрелку лучше добавить сразу.

## По словам агента

Пример: «Шаг прошёл, и в ответе агента есть „ГОТОВО К ДЕПЛОЮ“ → в Деплой».

Условие «только если агент написал…» проверяет итоговый комментарий агента.
Попросите агента в тексте задачи заканчивать отчёт условной фразой — и ветка с
этим условием сработает только по его решению. Условие доступно только на
исходах шага, где агент работал.

## По отметке на карточке

Стадия может ждать не события в репозитории, а отметки на карточке: человек
ставит «Одобрено = Да» — и карточка сразу едет дальше, без опроса. В списке
событий стрелки это «на карточке выбрано»; какая опция — её условие
(обязательное).

Стадия реагирует только на названное свойство: отметка «Приоритета» не
сработает для стрелки, ждущей «Одобрено». Если на карточке в этот момент
работала сессия, она отменяется — приоритет за человеком.

Карточка на такой стадии показывает в полоске маршрута, чего ждёт, вместе с
условием.
