# Руководство пользователя

Документация для того, кто работает с доской, — не для того, кто работает над
кодом. Техническое устройство описано уровнем выше, в [docs/](../).

- [Редактор: колонки, маршруты и правила](editor.md) — экран «Как работает эта
  доска…»: палитра блоков, холст, условия на переходах и редактирование
  шаблонов.
- [Как написать маршрут](flow.md) — тот же редактор со стороны задачи: собрать
  конвейер с нуля, в каком порядке принимать решения и что проверить.
- [«Входящие»](inbox.md) — как на доску попадает то, что вы не печатали:
  системное «Поделиться», Kaiten, скрипт или телефон по HTTP.
- [Перенос доски на другую машину](move.md) — что уезжает с доской архивом, а
  что придётся настроить заново, и почему граница проходит именно там.

Разделы добавляются по мере того, как фичи обрастают вопросами.
