# kaiten

MCP-сервер для [kaiten.ru](https://kaiten.ru): карточки, комментарии, чеклисты —
и `list_my_cards`, который XCIII читает как источник.

```
bun install
KAITEN_TOKEN=… bun run server.ts     # говорит по MCP в stdio
```

`KAITEN_SITE` задаёт домен (по умолчанию `https://vinokurov.kaiten.ru`),
`KAITEN_TOKEN` — токен из профиля Kaiten.

## Kaiten как источник XCIII — это не отсюда

Источник «Kaiten» встроен в приложение: меню доски → «Источники…» → выберите
**Kaiten**, впишите адрес, доску и токен. Ставить и копировать нечего — сервер
под ним написан на Go и живёт внутри бинарника (`internal/sources/kaiten`,
`xciii mcp kaiten`), именно чтобы источник из диалога не требовал ни bun, ни
чекаута, ни пути в форме.

Этот сервер — про другое: он даёт **агенту** весь Kaiten (карточки,
комментарии, чеклисты), а не список для ленты.

Рядом лежит `xciii-manifest-agent.json` — пример того, как этот сервер отдаётся
агенту-источнику: агент получает его инструменты плюс `inbox/file_item`, которым
складывает найденное в тот же конвейер. Чтобы им воспользоваться, положите файл
в `~/Library/Application Support/XCIII/sources/manifests/`, поправив `dir`
(абсолютный путь к этому каталогу) и вписав имя своего агента (`agent.agent`).
Манифест из каталога данных перебивает встроенный с тем же именем.

Как устроено отображение ответа в элемент — `internal/sources/mcpsource.go` и
[docs/sources.md](../docs/sources.md), §25.
